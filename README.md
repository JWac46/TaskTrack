# TaskTrack

This is a program that will let you add and view a list of task to be completed 

## Current Features

-[add_task] this will add a task to your list to be viewd at a later time
-[view_task] This will print out all of your tasks set up before

## Running the Program

Run py tasktrack.py in the terminal
You will be prompted to pick form 1,2,3 to add,view,exit respecivly

## Current Limitation

The Task will not save when the program finished running.
